## Milestone Scope

**Objective:** Add skill lifecycle tooling to GSD — create, audit, and tune skills through guided workflows with specialist agents sharing a common infrastructure of SMART criteria and structural conventions.

**Success Criteria (all met):**
1. ✅ Shared foundation is solid — SMART rubric and authoring guide published; convention tests pass
2. ✅ Any skill can be audited — `/gsd-audit-skill` produces comprehensive report with verdict and remediation
3. ✅ New skills start correct — `/gsd-build-skill` generates convention-compliant scaffolds passing structural checks
4. ✅ Existing skills can be improved — `/gsd-tune-skill` takes symptom, diagnoses via auditor, proposes fixes, commits after approval
5. ✅ Lifecycle is connected — Scaffolder validates via auditor, tuner diagnoses via auditor, `--fix` routes from auditor to tuner
