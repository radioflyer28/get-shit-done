<threat_model>
**Threats addressed by this plan:**

1. **Agent not recognized by routing logic (LOW):**
   If gsd-skill-scaffolder is not in agent-contracts.md, workflow routing that checks completion
   markers may fail silently or misroute.
   Mitigation: Task 1 adds the agent to the registry with both completion markers. The Marker
   Rules section in agent-contracts.md documents the ALL-CAPS convention used.

2. **Agent sandbox escape in Codex runtime (LOW):**
   Without a CODEX_AGENT_SANDBOX entry, the agent runs with default (potentially broader or
   narrower) permissions in OpenAI Codex runtime.
   Mitigation: Task 2 adds an explicit 'workspace-write' permission — the minimum required for
   creating files. Read-only agents use 'read-only'; write-capable agents use 'workspace-write'.

3. **bin/install.js syntax error from bad insertion (MEDIUM):**
   Incorrectly inserting the CODEX_AGENT_SANDBOX entry could break the install script for all users.
   Mitigation: Task 2 acceptance criteria includes `node -c bin/install.js` syntax check.
   Task 3 also runs the install script to confirm it executes correctly.
</threat_model>
