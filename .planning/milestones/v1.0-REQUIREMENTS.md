## Requirements Not Included (v2+)

The following were identified during planning but deferred to v1.1 or v2.0:

### Autonomous Skill Tuning (SEED-004)

- AUTO-01: Autonomous skill improvement loop using Karpathy autoresearch pattern
- AUTO-02: Audit scores as optimization metric
- AUTO-03: Session transcript analysis for automatic friction detection

### Ecosystem

- ECO-01: Skill marketplace or registry for sharing
- ECO-02: `--full` flag to generate complete working skills
- ECO-03: Skill versioning and changelog tracking
- ECO-04: Multi-skill batch auditing for quality sweeps

### Out of Scope for v1.0

| Feature | Reason | Target |
|---------|--------|--------|
| Autonomous tuning | Manual tuning proven first; large scope | v1.1+ |
| Skill marketplace | No sharing mechanism needed in v1 | v2.0+ |
| Skill versioning | v1 focuses on quality, not change tracking | v1.1+ |
| External contributor docs | build-skill handles creation | future |
| Scanner seeds (006-010) | Separate concern | separate milestone |
